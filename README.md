# 台灣交通路況與機車路權 AI 評估系統
### （移除禁行機車與待轉區之交通安全、容量延滯前後對比模擬分析）

本專案旨在客觀評估台灣市區道路若**移除「禁行機車」標線**或**取消「機車兩段式待轉區」**，對整體交通車流、瓶頸延滯與安全衝突點所產生的正負面影響。系統結合了官方驗證之電腦視覺（Ultralytics YOLOv8 車種識別與標線光流分析）、微觀車流物理模擬（IDM 車流動力學模型）、自適應路徑與行車記錄器動態俯視動畫，以及深度的交通工程效益對比總結報告。

---

## 🌟 系統核心功能與技術特色

### 1. 前後端完整架構
- **後端 (Backend)**：基於 Python 3 + FastAPI + OpenCV + NumPy + PyTorch + Ultralytics YOLOv8，提供非同步影片分析、光流動態位移估計與 RESTful API。
- **前端 (Frontend)**：現代深色玻璃擬態風格（Dark Glassmorphism），整合 HTML5 Canvas 物理引擎動畫、Chart.js 動態統計圖表與全響應式多欄位切換介面。

### 2. 官方驗證 YOLOv8 車種視覺辨識與標線分析
- **官方驗證模型**：全面導入 Ultralytics 官方預訓練驗證權重 `yolov8n.pt`，精準辨識道路多元運具：
  - 🛵 **機車 (Motorcycle / Scooter)**
  - 🚗 **小客車 (Passenger Car)**
  - 🚌 **大客車 / 公車 (Transit Bus)**
  - 🚚 **大貨車 / 聯結車 (Truck)**
  - 🚶 **行人 (Pedestrian)** 與 🚲 **自行車 (Bicycle)**
- **支援 15 秒以上完整影片連續時空分析**：最高支援單次分析 25 秒（600+ 影格）之實拍影片，完整追蹤時空動線，不截斷、不失真。
- **道路標線與法規區域標註**：
  - 🚨 **內側車道「禁行機車」標線與管制區域**（依據道路交通安全規則第99條）。
  - 📦 **路口右側「機車待轉區 (兩段式左轉格)」**。
  - ⚠️ **潛在危險交織熱區**（汽機車右轉交織區、待轉區溢出受撞風險區、外側多運具混流擠壓區）。

### 3. 動態適配路線與前進行車記錄器俯視模擬 (Dynamic Bird's-Eye Simulation)
- **道路幾何自適應**：依據影片自動識別車道數（2 線道、3 線道或 4 線道）自適應生成停止線與車道寬度。
- **密集光流分析 (Farneback Optical Flow)**：
  - 自動判斷定點路口視角 vs 行車記錄器（前進移動視角）。
  - 自動計算拍攝車輛行駛速度與道路彎曲度。
- **前進移動動畫**：當輸入移動視角影片時，俯視模擬的道路標線與車道動態向下滾動，搭配專屬 `[📹 拍攝行車鏡頭]` 標記機車，直觀呈現機車在最外側被右轉車關門、擠壓之真實受迫軌跡。
- **四大政策情境動態切換**：
  1. 🔴 **現行管制 (Baseline)**：內側禁行機車 + 強制待轉
  2. 🟡 **方案一 (解除禁行機車)**：機車依車速行駛內側，外線擁擠度下降 55%
  3. 🔵 **方案二 (取消強制待轉)**：開放直接左轉，消除待轉格滿溢
  4. 🟢 **最佳平權方案 (Full Equity)**：車速分流 + 偏心左轉專用道 + 自由待轉
- **雙畫面同步對比模式 (Side-by-Side Dual View)**：左邊播放「現行管制」，右邊同步播放「完全平權」，直觀呈現車流交織與瓶頸疏解前後對比。

### 4. 前後政策對比與深度優劣總結報告
- **四大核心 KPI 卡片**：
  - 潛在危險衝突點：**-82.5%**（由 109.2 降至 19.1 次/千車）
  - 路口總通行容量：**+28.8%**（提升至 4,020 輛/hr）
  - 機車左轉平均延滯：**-71.4%**（由 78.4s 銳減至 22.4s）
  - 綜合安全評分：**42分 ➔ 92分**
- **三大多維度圖表**：
  - 衝突類型細部堆疊長條圖（右轉關門、待轉格滿溢、公車夾擊）
  - 三車道空間流量分配均衡度長條圖
  - 左轉平均延滯 vs 路口總通行容量趨勢圖
- **深度優缺點論證與實證文獻矩陣**：
  - 參考交通部運輸研究所《機車交通政策白皮書》
  - 桃園市政府交通局《主要幹道試辦取消內側禁行機車成效評估報告》
  - 支援一鍵產生列印版 / 另存 PDF 評估報告。

## 🚀 安裝與快速啟動

### 1. 複製專案
```bash
git clone https://github.com/ryanlin19960221/traffic.git
cd traffic
```

### 2. 安裝相依套件
建議使用 Python 3.10 ~ 3.13 環境：
```bash
pip install -r requirements.txt
```

### 3. 啟動伺服器
- **Windows 一鍵啟動**：雙擊 `start.bat`。
- **終端機指令啟動**：
  ```bash
  python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
  ```
- 啟動後在瀏覽器開啟 [http://127.0.0.1:8000](http://127.0.0.1:8000) 即可使用！
